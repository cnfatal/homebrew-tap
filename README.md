# homebrew-tap

Homebrew Tap for [cnfatal](https://github.com/cnfatal) projects.

## Install

```bash
brew tap cnfatal/tap
brew install --cask network-status-bar
```

## Available Casks

| Cask | Description |
|------|-------------|
| `network-status-bar` | macOS menu bar tool for monitoring real-time network traffic per process |
